# 3DCG 長尺動画 企画10本（2026-10-28 案・オーナーの Go/No-Go 待ち）

共通ルール
- 既存の動画と重ねない。釣り場ガイド・海上釣り堀・道具紹介はやらない。
- 最初の10秒で「答えが知りたくなる問い」を出す。20〜40秒ごとに画面を切り替える（カメラ移動・章タグ・ラベルの出現）。
- 章の最後に小さなまとめを入れる。最後にコメントで答えられる質問を出す。
- 事実だけを言う。言い切れないことは「〜と言われます」とする。立入禁止の場所は映さない・勧めない。
- 制作：three.js の3DCGで描き、VOICEVOX のナレーションを付ける。1本 3〜6分。

## 制作メモ
- 描画は Actions で8分割して並列に描く（3〜4分の動画で約30分）。
- 魚の絵はサイトの魚イラストを3Dの板に貼り、尾を動かす。
- 5（データ）は data/ の釣果だけを使い、出典をはっきり言う。
