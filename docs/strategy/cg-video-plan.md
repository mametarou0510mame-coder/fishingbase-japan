## 制作メモ
- 描画は Actions で8分割して並列に描く（3〜4分の動画で約30分）。
- 魚の絵はサイトの魚イラストを3Dの板に貼り、尾を動かす。
- データを使う動画は data/ の釣果だけを使い、出典をはっきり言う。
- 「見える化」が伸びた理由（10/30 Instagram：潮目・ヨレ・反転流のショートが19時間で11万回）：①見えないものが光る粒で見える最初の1秒、②釣れる場所が分かる実用、③クイズ、④人に教えたくなる。
- アカデミー：タイトルの頭に【ツレドキアカデミー】、右上にバッジ（academyBadge()）、出典の機関名を画面と言葉の両方で出す。

## わかりやすさの作り（2026-10-30 オーナー承認。これを基本にする）
見本：content/cg/short-cg-jissen.json と main.js の js_*（makeArrow／arrow・target・miniMap・legend・bigText・topView、updateFlow の focus）。
- 1画面に伝えることは1つ。説明中の場所だけはっきり、ほかは薄く（updateFlow の focus）。
- 向きは太い矢印、答えは緑の脈打つ円と大きな「ここ！」ラベル（.lab.ans）。
- 全体図（左上）で今どこを見ているかを示す。凡例（右上）の色の意味はシリーズで固定：水色＝速い流れ／海の水、オレンジ＝ゆるい流れ／川の水、緑＝投げる場所・正解、赤＝危険。
- 字幕は短く1〜2行。caps で読み上げとは別に短い字幕を出し、大事な言葉は [[ ]] で黄色にする。
- 真上に近い角度で、ゆっくりしたカメラ。暗い画面・粒子感・周辺の暗さは使わない。
- かっこよさ（画面転換・文字の動き）とリアルさは、この上に少しずつ足し、毎回サンプルでオーナーに確認する。

## 見た目の仕上げ（v2、2026-10-30）※オーナー判断で保留。「わかりやすく見やすい」が最優先。かっこよさ・リアルさはその後
- main.js に POST（光のにじみ・色の調整・周辺減光・フィルムの粒子・色ずれ）を追加。光る粒（流れ・プランクトン・しぶき）が特に映える。?look=v1 で従来の見た目。
- 陸地をなめらかな模様に、海面に細かいきらめきを追加。
- 次にやること：BGM と効果音（合成で作る）、文字の動き（スライド・数字のカウントアップ）、魚に厚みと陰影。

## YouTube の伸ばし方（2026-11-01 オーナー OK）
1. 毎日の定型リール（spots・deals・tomorrow・weekend・hot・flash・update）は Instagram だけに出す。YouTube ショートは 3DCG・アカデミー・豆知識（trivia）・釣り方ガイド・長尺の予告編に絞る（1日4〜5本）。
   理由：YouTube は 2025-07-15 から「同じナレーションのスライドショー」などを大量生産の例として挙げている。おすすめは視聴時間・満足度も見る。
   実装：scripts/sns/reels.py の YT_SLOTS。
2. 長尺の冒頭：つかみのあと、タイトルだけの画面（by_title・sw_title など）は入れない。すぐ一番おもしろい絵へ。
3. YouTube のタイトルは中身（問い）を先に、シリーズ名【…】は後ろ（scripts/sns/yt_long.py の yt_title）。サムネの文字は8文字前後まで大きく、3DCG の絵を主役に。
4. （オーナー作業）再生リスト「ツレドキアカデミー」「3DCG 見える化」、ショートに関連動画（フル版）を設定。
5. （オーナー作業）YouTube の鍵を youtube.readonly・yt-analytics.readonly 付きで作り直す → yt-stats.yml で毎週の分析ができる。
