# 釣り場の追加候補（定期更新）

## ルール

- 載せるのは、公式情報（施設・自治体・観光協会・国）で確かめられたものだけ。
- 立入禁止・釣り禁止・休園中のところは載せない。
- 自分で開けない公式URLは、オーナーに承認してもらってから確認する。
- robots.txt で拒否されているサイトは読まない。
