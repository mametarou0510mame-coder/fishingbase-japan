# 長尺動画（YouTube）企画リスト

方針（2026-10-30 変更）：長尺は1日2本（07:17・18:17 JST）。投稿待ち（scripts/sns/yt_long.py の ORDER のうち data/sns/long-posts.json にないもの）が14本を切ったら、18本になるまで足す（1回に最大8本）。

作らないテーマ（オーナー判断）：エリア別の釣り場ガイド、海上釣り堀ガイド、おすすめ道具・釣具紹介（lib/affiliate.ts の AMAZON_TAG が入り、オーナーが指示するまで）。

伸ばす型：最初の15秒で意外な数字・結論の一部／「〇〇は本当？」のデータ検証／旬の話題／クイズ／コメントしたくなる質問。

- 「雨の日は釣れる」は本当？ 釣果データで検証
  - 保留理由（2026-10-26）：雨の記録（過去の日ごとの降水量）がサイトのデータにない。気象庁の過去の気象データを data/history/ に取り込む仕組み（GitHub Actions から取得）ができたら作る。
- 【注意喚起】知らなかったでは済まない「密漁」 釣り人が気をつけるルール
  - 季節もの：潮干狩りの注意は3〜4月 → 2月中旬〜3月上旬に投稿されるように作る。磯遊びの貝・ウニ・タコの注意は6〜7月 → 5月下旬〜6月中旬に投稿。
  - 必ず公的な原文で確認：改正漁業法（令和2年12月施行）の特定水産動植物（アワビ・ナマコ）＝3年以下の拘禁刑または3,000万円以下の罰金、密漁品と知りながら買う・運ぶ・保管も同じ／漁業権侵害＝100万円以下の罰金／大阪府チラシ https://www.pref.osaka.lg.jp/documents/7970/chirashi_genbatsu.pdf

- 【データで見る】関西で釣れる魚のサイズ（サイト投稿・公開釣果のサイズ記録がたまったら）
