# 3DCG 動画：作りかけの引き継ぎメモ

**どの回のセッションでも、3DCG の作業を始める前にこのファイルを読む。** 作りかけがあれば、新しい企画を選ばずに「次にやること」から続ける。
作業が1つ進むたびに、このファイルのチェックを更新して commit・push する（利用上限で止まっても、別のモデル・別のセッションが続きから再開できるようにするため。2026-11-16 オーナー依頼）。

使い回せる部品の一覧は docs/strategy/cg-assets.md。

**早く・少ないトークンで作る決まり（2026-11-22 オーナー。画質・設定は変えない）**
- Actions の結果は `sh scripts/cg/tools/run_brief.sh <実行ID か ワークフロー.yml>` で見る。終わるまで黙って待ち、結果・notice・エラーだけ出す。`gh run view --log` を全部読まない。途中で何度も見に行かない。
- 確認は小さい一覧画像1枚（`sheet.sh`、ふだん 640×360 を4枚）。細部を見るときだけ `W=960 H=540`。
- Blender は test（低画質・数コマ）で確かめてから full を1回。ショート（cg-short）は1本を4つに分けて同時に書き出す（chunks）。
- 制作済みの一覧は cg-done.md（新しい企画を選ぶときだけ読む）。

**魚の色は 3D モデルのまま（2026-11-22 オーナー）**：魚の色を水中の見え方に加工しない。色の見え方が主題の回だけ加工あり。くわしくは cg-video-plan.md の共通ルール。
