# ショート（YouTube ショート・Instagram リール）を伸ばす方針（2026-11-06 調査）

## 公式・報道で確かめたこと
- YouTube：ショートの「視聴を選択したユーザー数」（見た人とスワイプで離れた人の割合）と、総再生時間・視聴者維持率が大事な指標（YouTube ヘルプ「[コンテンツ] タブの分析に関するヒント - ショート」）。
- YouTube：2025-03-31 から、ショートの視聴回数は再生・再再生のたびに数える。前の数え方は「エンゲージビュー」（収益・YPP はこちら）（TechCrunch 2025-03-26）。
- Instagram：リールの届き方は、視聴時間（何%・何秒）が決め手。いいね／リーチはフォロワーへ、シェア（送る）／リーチはフォロワー以外へ広がる力が大きい（Mosseri の説明のまとめ、fanpagekarma 2025）。オリジナルであること・他アプリの透かしなし。
- Instagram：2025-12-19 からハッシュタグは1投稿5個まで。少なく具体的なタグのほうがよい。届き方は、キャプションの言葉・画面の文字・映像の中身で決まる比重が大きい（@creators の発表、Business Today ほか）。
- Instagram：試験的なリール（Trial Reels）で、まずフォロワー以外に見せて反応を試せる（2024年末から。API は trial_params.graduation_strategy＝MANUAL / SS_PERFORMANCE）。

## うちの実績
- 伸びた：L字の堤防・港の入り口（Instagram 23.3万回、いいね1,113、送る62、リポスト46、コメント15）。最初のコマに堤防とA・B・Cがあり「自分ならどこ？」と考えられる。くわしい人の反論コメントが付いた。

## 決まりごと（これからの投稿）
1. 最初の1コマで「問い」と「見て分かる絵」を出す（タイトルの帯・A/B/C・数字）。フェードで始めない。
2. 答えを言う前に、見る人が考える間を作る（クイズ・A/B/C）。答え合わせは最後の方に。
3. 30秒前後を目安。エンドカードは短く（3〜3.5秒）。
4. 送りたくなる・保存したくなる中身（現場で使える答え、仲間と答え合わせ）。最後に「コメントで」「釣り仲間に送って」と呼びかける。
5. ハッシュタグは5個まで（#PR → 具体的なタグ → 共通のタグ）。キャプションの1行目に検索される言葉（魚・場所・釣り方）。
6. コメントには、投稿から1時間ぐらいのうちに返す（オーナー）。反論コメントは次の企画のヒントにする。
7. 新しい型は試験的なリールで試す（content の short に "trial": true）。
8. 数字（スワイプ率・維持率・保存・送る）を毎週集めて、伸びた回の共通点を表にする（Instagram の insights 権限、YouTube Analytics の権限が必要）。
